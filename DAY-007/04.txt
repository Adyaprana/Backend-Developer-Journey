INTERVIEW QUESTIONS


Q1. What is Backend?
Answer: Backend is the server-side part of an application responsible for business logic, 
databases, APIs, authentication, and processing.

Q2. What is Frontend?
Answer: Frontend is the user interface users interact with.

Q3. What is API?
Answer: API allows different software systems to communicate.

Q4. What is JSON?
Answer: JSON is a lightweight format used to exchange data between systems.

Q5. Why are Dictionaries important?
Answer: Because API responses and JSON data map directly to dictionaries.

Q6. Why are Lists important?
Answer: Used to store collections of records.

Q7. What is Database?
Answer: Permanent storage for application data.

Q8. What is SQL?
Answer: Language used to interact with relational databases.

Q9. What is FastAPI?
Answer: A modern Python framework used for building APIs.

Q10. Why learn Python Backend instead of random technologies?
Answer:  Depth beats breadth.
