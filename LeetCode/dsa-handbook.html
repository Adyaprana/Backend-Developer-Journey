// how to use this handbook

  1. Go top to bottom, tier by tier. Don't skip ahead to Trees while Arrays patterns are unfinished — patterns stack on each other.
  2. Inside a structure, do every pattern in order. Finish all Easy in a pattern → Medium → Hard, then move to the next pattern.
  3. For every problem: identify the pattern first (before reading editorial) → brute force → optimize → clean Python → time/space complexity → 1-line note in your DSA notebook.
  4. Click the checkbox next to a problem once it's Accepted. Progress updates live (resets if you refresh the page — keep your real source of truth in your notebook/sheet).
  5. Use the search bar and Easy/Medium/Hard filters above to jump around once you've started.
