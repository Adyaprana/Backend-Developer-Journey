// The actual plan

12-Month Roadmap

01
Foundation: Learn to Actually Code
Months 1–3 · June–Aug 2026

"By end of Month 3 you can write Python without AI help, build a working API, and understand what you wrote."

🐍
Weeks 1–3
Python Core — The Real Way
Variables, loops, functions, OOP (classes, inheritance), error handling, file I/O, list comprehensions. Don't skip OOP — every interview asks it. Use: CodeWithHarry Python playlist (Hindi) or Corey Schafer Python OOP (English). Goal: Write 20 small programs from scratch with no AI.
🌐
Weeks 4–5
How the Web Works (Non-Negotiable)
HTTP methods (GET, POST, PUT, DELETE, PATCH), status codes (200/201/400/401/403/404/500), JSON, headers, request/response cycle. You will be asked this in every interview. Use: Traversy Media HTTP Crash Course (30 mins, free YouTube).
⚡
Weeks 5–8
FastAPI — Your Core Framework
Routes, path params, query params, Pydantic models for validation, response models, dependency injection basics, async/await, Swagger docs auto-generation. Use: Official FastAPI docs (best docs in Python world) + Coding Entrepreneurs FastAPI YouTube. Build: A working TODO API with full CRUD.
🗄️
Weeks 6–10
SQL + PostgreSQL (Parallel with FastAPI)
SELECT, INSERT, UPDATE, DELETE, JOIN (inner/left/right), WHERE, GROUP BY, ORDER BY, LIMIT. Then: indexes, primary keys, foreign keys, transactions. Practice: SQLZoo.net (free), Mode Analytics SQL Tutorial. Then connect to FastAPI using SQLAlchemy ORM.
🔧
Weeks 8–10
Git + GitHub — Properly
git init, add, commit, push, pull, branching, merging, resolving conflicts, pull requests. Write meaningful commit messages. Every project must be on GitHub with a README. Use: Kunal Kushwaha Git & GitHub (Hindi/English) — 1 video, covers everything.

✓ Phase 1 Checkpoint — Can you do all of this?

  • Write a Python class with methods without Googling
  • Build a FastAPI with 5 endpoints from scratch
  • Write a SQL JOIN query and explain it
  • Push your code to GitHub with clean commits
  • Explain what happens when you call a REST API
  • Handle errors and return proper HTTP status codes
02
Depth: Build Real Stuff
Months 4–6 · Sep–Nov 2026

"By end of Month 6 you have 2 portfolio-worthy projects deployed live that interviewers will ask about."

🔐
Weeks 1–3
Authentication & Security
JWT tokens (access + refresh), OAuth2 password flow in FastAPI, bcrypt password hashing, middleware, CORS. These come up in EVERY backend interview. Understand: what is a token, where to store it, how to verify it, what happens on expiry.
🏗️
Weeks 2–5
Database Design (Schema)
Normalization (1NF, 2NF, 3NF — just understand the concept), relationships (one-to-many, many-to-many), indexing strategy, Alembic migrations with SQLAlchemy. Practice: design DB schema for Instagram, Twitter, e-commerce. This is a system design lite question asked at startups.
🐳
Weeks 4–6
Docker — Just the Basics
What is a container, Dockerfile, docker build, docker run, docker-compose (run FastAPI + PostgreSQL together locally). You don't need Kubernetes. Just containerize your project so you can deploy it. Use: TechWorld with Nana Docker Beginner (YouTube, English).
📦
Weeks 5–8
Redis — Caching Basics
What is caching and why it matters, Redis data structures (strings, hashes, lists), TTL, cache-aside pattern, session storage. Not deep — just know: what is Redis, when to use it, basic implementation with FastAPI. This differentiates you from most freshers who have never touched it.
🧪
Weeks 7–10
Testing — pytest
Unit tests, integration tests for APIs using pytest and httpx test client in FastAPI. How to mock database calls, test coverage basics. Most freshers skip this — knowing it makes you look senior. Write tests for your own projects.

✓ Phase 2 Checkpoint

  • Explain JWT auth end-to-end without notes
  • Design a database schema on paper in 10 minutes
  • Run your project with docker-compose up
  • Explain what Redis is and when you'd use it
  • Show 10+ unit tests for your API
  • Project 1 is deployed on Railway/Render/AWS EC2
03
Cloud + Interview Prep Begins
Months 7–9 · Dec 2026–Feb 2027

"By end of Month 9 you can answer 80% of backend interview questions and have AWS basics on your resume."

☁️
Weeks 1–4
AWS Fundamentals (Core 4 Only)
EC2 (deploy your FastAPI here), S3 (store files/images), RDS (PostgreSQL on cloud), Lambda basics (serverless concept). That's it. No need for deep AWS. Get AWS Cloud Practitioner cert — ₹0 to study, ₹8,000 to appear. AZ-900 you already have — AWS adds more weight. Use: FreeCodeCamp AWS Practitioner Course (YouTube) — 14 hours, free.
🔄
Weeks 3–6
CI/CD Basics
GitHub Actions — auto run tests on push, auto deploy to server. Setup a basic pipeline: push code → tests run → deploy. This shows you understand real-world engineering. One working pipeline on your GitHub is enough. Use: TechWorld with Nana CI/CD YouTube.
💬
Weeks 5–10
System Design Basics (Startup Level)
Not Google-level system design. Startup level: Design URL shortener, design a backend for Instagram-like app, design an e-commerce cart. Topics: scalability concepts, load balancing (concept only), database sharding (concept), CDN (concept), message queues (concept). Use: Gaurav Sen System Design YouTube (English, incredible quality).
❓
Ongoing from Month 7
Interview Q&A — Start Now
Core Python Qs: OOP concepts, decorators, generators, context managers, GIL, mutable vs immutable. FastAPI Qs: async vs sync, Pydantic validation, dependency injection, middleware. DB Qs: indexing, N+1 problem, transactions, ACID. REST Qs: idempotency, statelessness, versioning, status codes. Use: InterviewBit, GeeksForGeeks Python backend section.

✓ Phase 3 Checkpoint

  • Deploy a FastAPI app on AWS EC2 (live URL)
  • CI/CD pipeline running on your GitHub
  • Can design URL shortener system on whiteboard
  • Answer 30 Python interview questions correctly
  • AWS Cloud Practitioner exam booked or passed
  • Project 2 is deployed, documented, on GitHub

DSA: How Much Do You Actually Need?

The honest answer for your target (Bangalore startups, 10 LPA)

You do NOT need competitive programming. You do NOT need 500 LeetCode problems. But you need the basics — here's exactly what:

Topic Why Level
Arrays + Strings Every OA has these. Most used in backend code. Must
HashMaps / Dicts Most real-world backend problems use this Must
Two Pointers Common in startup OAs Must
Sorting basics Asked in phone screens frequently Must
Linked Lists Classic interview topic, concept only Basic
Binary Search Appears in medium-level OAs Basic
Stack / Queue Used in real backend code too Basic
Trees / Graphs Only for FAANG/MNC — skip for now Skip
Dynamic Programming Only for big companies — skip for now Skip

Target: 50–75 LeetCode Easy/Medium problems. Spend 30 min/day from Month 7 onward. Use: NeetCode.io (best roadmap) + Striver's A2Z Sheet (first 2 sections only).

Category Must-Know Topics Priority

Testing pytest basics, unit vs integration tests, mocking, test coverage concept 🟢 P3
